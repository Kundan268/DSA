# Phase 1: JavaScript Core Basics

Welcome to Phase 1! This phase covers the fundamental building blocks of JavaScript that you'll use throughout your DSA journey.

## 📚 What You'll Learn

1. **Variables & Data Types** - How to store and work with different types of data
2. **Operators & Expressions** - How to perform calculations and comparisons
3. **Control Flow** - How to make decisions and repeat actions

## 📁 Files in This Phase

- `01-variables-and-data-types.js` - Learn about variables (let, const, var) and all data types
- `02-operators-and-expressions.js` - Arithmetic, comparison, logical operators, and more
- `03-control-flow.js` - If/else, switch, loops (for, while, do-while), break, continue
- `04-exercises.js` - Practice problems to test your understanding

## 🚀 How to Use These Files

1. **Start with the tutorial files** (01, 02, 03):
   ```bash
   node 01-variables-and-data-types.js
   node 02-operators-and-expressions.js
   node 03-control-flow.js
   ```

2. **Read the code and comments** - Each file has detailed explanations

3. **Modify and experiment** - Try changing values and see what happens!

4. **Practice with exercises** - Open `04-exercises.js` and try solving the problems

5. **Check solutions** - Uncomment the solutions at the bottom to verify your answers

## 📝 Learning Tips

- **Type out the code yourself** - Don't just read, actually write it
- **Experiment** - Change values and see what happens
- **Solve exercises** - Practice is key to understanding
- **Ask questions** - If something doesn't make sense, experiment more!

## ✅ Completion Checklist

- [ ] Understand the difference between `let`, `const`, and `var`
- [ ] Know all 7 primitive data types
- [ ] Can use `typeof` to check data types
- [ ] Understand `==` vs `===` (loose vs strict equality)
- [ ] Can use arithmetic, comparison, and logical operators
- [ ] Understand ternary operator (`? :`)
- [ ] Can write if/else and switch statements
- [ ] Can use for, while, and do-while loops
- [ ] Understand `break` and `continue`
- [ ] Can iterate through arrays and objects
- [ ] Completed all exercises in `04-exercises.js`

## 🎯 Key Concepts for DSA

These concepts are especially important for Data Structures and Algorithms:

- **Arrays** - You'll use arrays constantly in DSA
- **Loops** - Essential for iterating through data structures
- **Comparison operators** - Used in sorting, searching, and comparisons
- **Control flow** - Needed for algorithms and problem-solving logic
